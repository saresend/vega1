    03what is this

    Vega1-cat is a local System 1 model for category questions about video. You write a question and two or more options. The model selects the option that agrees with the video. It also gives the probability of each option.

    "System 1" is the fast type of human thought that gives an immediate answer. Vega1-cat does not write text, and it does not show its steps. It examines a video one time. Then it answers all of your questions in one step.

    Vega1-cat uses the same structure as the TypeSafe Jev System One API: choice questions in, typed answers out. The state is a video. For yes/no statements, use Vega1. The two models use the same video embeddings.

    The full model operates on your device, in this browser tab. It operates on a laptop or on a phone. The model does not send the video or your questions to a server.

    04how it works

    ┌─ your browser ────────────────────────────────────────────┐

│  video ─────────────> image encoder ──> frames ─┐         │
│                                                 ├─> dog   │

│   dog, cat, horse ──> text encoder ──> options ─┘         │
│                                                           │

    • frames The model takes 16 frames from the video. The MobileCLIP-S0 image encoder makes an embedding of each frame and of 6 close-up crops of 4 frames.
    • options The text encoder makes an embedding of each option, together with the question.
    • answer head An attention head with 1 million parameters compares the frames with each option. It gives a probability for each option. The probabilities add up to 100%. We trained the head on 61,000 category questions with labels: objects, animals, places, ground surfaces, sports, activities, the number of people, color, text on the screen and computer graphics.
    • speed The model embeds a video one time. After that, each question takes approximately 20 milliseconds.

    05limits

    • The model always selects one option. It has no "none of these" answer. If no option is correct, the probabilities are low and similar. Add an option such as "no animal" if necessary.
    • We did not train the model on colors of objects ("what color is the van?"). These answers are frequently not correct.
    • The model can miss very small objects, also with the close-up crops.
    • The model cannot count exactly. Use options such as "no people", "one person" and "a group of people".
    • Text on the screen can change the answers, because the encoder reads the text.
    • The model examines only the sampled frames. It does not see events between these frames.
